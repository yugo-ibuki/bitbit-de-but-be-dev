# LAST LIGHT

PixiJS v8 で作った短編 2D 探索ホラーゲームです。暗い施設で3個のヒューズを集め、追跡者に触れられる前に非常口から脱出します。

## 起動

```bash
npm install
npm run dev
```

表示されたローカル URL をブラウザで開き、`ENTER THE WARD` を押してください。

## 操作

- `WASD` + マウス: 左手で移動し、右手で懐中電灯を独立して照準
- 矢印キーだけ: 移動方向へ懐中電灯を自動照準
- `P`: 一時停止・再開
- `PAUSE` / `RESUME`: キーボードとタッチの両方で一時停止・再開
- タッチ端末: 画面左下の方向ボタンで移動し、移動方向へ懐中電灯を自動照準
- `RESTART`: 最初からやり直す

## ルール

施設内の緑色に点滅するヒューズへ近づくと自動で回収します。3個すべてを集めると北東にある非常口が緑色に変わります。黒い影に接触するとゲームオーバーです。

## 検証

```bash
npm test
npm run typecheck
npm run build
```

実験条件は `EXPERIMENT.md`、実測結果は `RESULTS.md` に記録します。
