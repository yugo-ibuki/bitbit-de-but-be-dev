# Daily Challenge Deck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace free shape selection with a deterministic Japan-time daily deck of 100 fixed shape/size pieces and store a separate best height for each daily challenge.

**Architecture:** Pure challenge helpers generate a quota-controlled deck from a date seed. `GameState` tracks consumed pieces separately from live physics objects, while `App` uses the current deck entry to create scaled items and passes current/next entries to the HUD.

**Tech Stack:** React 19, TypeScript, React Three Fiber, Rapier, Vitest, Testing Library, CSS
