# 積み上げラボ計測UI 設計

## 目的

現在の3D積み上げゲームに、積む行為の手応えと画面の情報量を追加する。既存の操作を邪魔せず、積み上げた高さが伸びる楽しさを明確にする。

## 承認済みの方向性

- テーマは「積み上げラボ」
- 見た目の装飾と実際に動くゲーム要素を両方追加する
- 主な計測値は「現在の高さ」と「ベスト記録」
- ベスト記録はブラウザに保存し、再起動後も復元する
- 既存の形選択、物体数、操作説明、リセット、破壊操作は維持する

## UIデザイン

画面左上に半透明の計測パネルを置く。パネルには現在の高さを大きく、ベスト記録を小さく表示する。単位はメートルで、小数第2位まで表示する。

3D空間には以下を追加する。

- プラットフォーム付近から上に伸びる高さ目盛り
- タワーの最高点を示す水平の計測ライン
- ラボらしい薄い床グリッド
- 操作を妨げない少量の浮遊粒子
- 既存の紫系配色を基調に、計測要素へシアンと黄緑のアクセント

モバイルでは計測パネルを縮小し、既存の形選択パネルや下部ボタンと重ならない位置に保つ。目盛りは簡略化しても、現在値とベスト値は常に読める状態にする。

## 高さの計測

高さは、物体の初期配置値ではなくRapierが管理する実際の当たり判定から求める。各有効な物体のワールド座標上のAABB上端を取得し、プラットフォーム上面を0メートルとして最大値を現在の高さにする。物体がない場合は0とする。

表示更新は毎フレームのReact再描画を避けるため一定間隔に制限し、センチメートル単位に丸めた値が変化した場合だけアプリへ通知する。計測ラインは同じ現在値を使用する。

ベスト記録は、 containment が有効な積み上げ中だけ更新する。「破壊する」を押した後の吹き飛びによる高さは記録対象にしない。破壊時はその回の到達値を固定し、リセット時に現在値だけ0へ戻す。

## 状態と保存

`App`が現在の高さとベスト記録を保持する。`GameScene`は物理空間から計測した高さをコールバックで通知し、HUDと3D計測ガイドは同じ値を受け取る。

ベスト記録はバージョン付きの専用キーで`localStorage`へ保存する。読み込み値が数値でない、負数、無限値、壊れたJSONの場合は0として扱う。ストレージが利用できない環境では例外を外へ出さず、セッション内の記録だけでゲームを続行する。

## コンポーネント境界

- `GameScene`: 物理ボディの計測と高さ通知を担当する
- `MeasurementGuide`: 3D空間の目盛り、計測ライン、グリッド、粒子を描画する
- `GameHud`: 現在値とベスト値を計測パネルとして表示する
- 高さ計算と記録保存は純粋関数／小さなヘルパーへ分離し、表示や物理描画から独立してテストできるようにする

## データフロー

1. `GameScene`が有効な物理ボディのAABBを一定間隔で確認する
2. 最大の上端から現在の高さを算出し、変更時だけ`App`へ通知する
3. `App`が積み上げ中の値を現在値へ反映し、過去最高ならベスト記録も更新する
4. `GameHud`と`MeasurementGuide`が同じ現在値を表示する
5. ベスト更新時に保存を試み、失敗しても画面とゲーム進行は維持する

## テスト

- 複数のAABBから最大高さを算出できる
- 負の値と物体なしを0に補正できる
- 破壊後の値でベスト記録が更新されない
- 正常な保存値を復元できる
- 不正な保存値やストレージ例外を0として扱える
- HUDが現在値とベスト値を正しい書式で表示する
- リセット後は現在値だけ0になり、ベスト値は残る
- デスクトップとモバイルの実ブラウザで、既存操作との重なりがない

## 対象外

- スコア、コンボ、重量、安定度
- ランク、ミッション、チャレンジモード
- サーバー同期やユーザーアカウント
- 破壊後の高さを記録する仕組み

## 完了条件

- 積み上げ中の現在高さが実際の物理状態に追従する
- 破壊による上方向の吹き飛びがベスト記録へ混入しない
- ベスト記録がリロード後も維持される
- 計測UIと装飾が既存の操作を妨げない
- 自動テスト、型チェック、本番ビルドが成功する
